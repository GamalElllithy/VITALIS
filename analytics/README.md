# Analytics

This area is for documented research and later analysis, not medical algorithms at this stage.
- notebooks/: exploratory, reproducible research with provenance and limitations.
- src/vitalis_analytics/: reusable Python analysis code.
- tests/: unit and integration validation.
Potential topics include data research, personalized baselines, trend analysis, data quality assessment, and explainable signal generation. These are goals to investigate, not validated capabilities. Future methods require evidence, provenance, validation, and human review. Scikit-learn is not assumed; justify it only if a need is established.
