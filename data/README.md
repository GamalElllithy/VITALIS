# Data

- raw/: original research datasets, only when source and usage permission are documented.
- interim/: temporary cleaned or transformed datasets.
- processed/: datasets prepared for analysis.
- samples/: small synthetic or approved demonstration datasets.
Real datasets require a documented source, license or usage terms, collection context, and permission. Record quality limitations and provenance. Clearly label simulated data; never present it as research evidence. Do not store personal health records or identifiable data. Large payloads are ignored by default; README and .gitkeep files remain trackable.
