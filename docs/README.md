# Documentation guide

- architecture/: system boundaries, data-flow questions, offline-first design.
- api/: API conventions and endpoint catalog.
- data/: field definitions, provenance, and quality.
- research/: research questions and verified source register.
- design/: screen planning and interface principles.
- team/: ownership and collaboration workflow.
- safety/: privacy, security, and medical safety boundaries.
- decisions/: Architecture Decision Records.
- testing/: planned validation strategy.
Templates contain TODOs where the team has not decided. Update documentation alongside implementation and cite real sources only after verification.
