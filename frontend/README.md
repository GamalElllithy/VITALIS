# Frontend

Planned React, TypeScript, and Vite client; this directory is organizational only, not an application yet.
- public/: static files.
- src/app/: app composition, routing, and providers.
- src/assets/: imported media and static assets.
- src/components/layout/: page shells and navigation.
- src/components/shared/: reusable domain-aware components.
- src/components/ui/: general interface primitives.
- src/features/: dashboard, health-profile, observations, signals, passport, and mission features.
- src/hooks/: reusable React hooks.
- src/lib/api/: API client helpers.
- src/lib/offline/: planned local persistence and synchronization integration.
- src/lib/utils/: general helpers.
- src/styles/: global styles and Tailwind entry points.
- src/types/: shared TypeScript types.
- tests/unit/ and tests/e2e/: planned Vitest and Playwright tests.
